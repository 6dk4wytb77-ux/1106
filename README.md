# 拾光｜個人學習行程與任務管理系統

拾光是一套響應式個人學習規劃前端原型，支援今日學習、週行程與所有任務工作區。

## 功能

- 今日學習清單、每日切換與完成進度摘要
- 週行程總覽，可切換週別、由日期進入單日、由任務開啟編輯
- 所有任務清單，支援科目與完成狀態篩選
- 完整任務新增／編輯表單：名稱、科目、優先順序、學習日期、截止日、時段、預估時間與備註
- 科目分類管理
- 使用瀏覽器 `localStorage` 保存任務與分類
- 桌機側欄導覽、手機底部導覽與自適應版面

## 開始使用

不需安裝套件。以瀏覽器開啟 `index.html` 即可體驗。

## 資料保存說明

目前資料僅保存在目前瀏覽器的本機儲存空間；不會自動跨瀏覽器或跨裝置同步。清除網站資料可能會移除已建立的任務。

## 專案檔案

- `index.html`：頁面結構
- `styles.css`：桌機／手機響應式樣式
- `app.js`：頁面互動、任務管理與本機保存
- `PRD_個人學習行程與任務管理系統.docx`：產品需求文件
